How the code UTKS0001675 is built

UTKS is the bank part: the letters of Utkarsh Small Finance Bank. The fifth character is always the digit 0. 001675 is the part that names this branch.

The MICR code 700762011 is the number printed along the bottom of this branch's cheques. 700 is the city (the same three digits that begin the PIN code 700004), 762 is the bank and 011 is the branch.
