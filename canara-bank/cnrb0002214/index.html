How the code CNRB0002214 is built

CNRB is the bank part: the letters of Canara Bank. The fifth character is always the digit 0. 002214 is the part that names this branch.

The MICR code 700015028 is the number printed along the bottom of this branch's cheques. 700 is the city (the same three digits that begin the PIN code 700007), 015 is the bank and 028 is the branch.
