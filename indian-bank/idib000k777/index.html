How the code IDIB000K777 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00K777 is the part that names this branch.

The MICR code 700019121 is the number printed along the bottom of this branch's cheques. 700 is the city (the same three digits that begin the PIN code 700033), 019 is the bank and 121 is the branch.
