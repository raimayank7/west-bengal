How the code IDIB000C616 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00C616 is the part that names this branch.

The MICR code 721019405 is the number printed along the bottom of this branch's cheques. 721 is the city (the same three digits that begin the PIN code 721633), 019 is the bank and 405 is the branch.
