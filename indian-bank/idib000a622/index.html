How the code IDIB000A622 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00A622 is the part that names this branch.

The MICR code 700019124 is the number printed along the bottom of this branch's cheques. 700 is the city, 019 is the bank and 124 is the branch.
