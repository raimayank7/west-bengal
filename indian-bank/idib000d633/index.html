How the code IDIB000D633 is built

IDIB is the bank part: the letters of Indian Bank. The fifth character is always the digit 0. 00D633 is the part that names this branch.

The MICR code 742019102 is the number printed along the bottom of this branch's cheques. 742 is the city (the same three digits that begin the PIN code 742202), 019 is the bank and 102 is the branch.
