How the code UCBA0002222 is built

UCBA is the bank part: the letters of UCO Bank. The fifth character is always the digit 0. 002222 is the part that names this branch.

The MICR code 722028157 is the number printed along the bottom of this branch's cheques. 722 is the city (the same three digits that begin the PIN code 722157), 028 is the bank and 157 is the branch.
