How the code UCBA0002176 is built

UCBA is the bank part: the letters of UCO Bank. The fifth character is always the digit 0. 002176 is the part that names this branch.

The MICR code 723028126 is the number printed along the bottom of this branch's cheques. 723 is the city (the same three digits that begin the PIN code 723126), 028 is the bank and 126 is the branch.
