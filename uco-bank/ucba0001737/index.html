How the code UCBA0001737 is built

UCBA is the bank part: the letters of UCO Bank. The fifth character is always the digit 0. 001737 is the part that names this branch.

The MICR code 712028301 is the number printed along the bottom of this branch's cheques. 712 is the city (the same three digits that begin the PIN code 712223), 028 is the bank and 301 is the branch.
