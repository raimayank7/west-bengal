How the code UTIB0006045 is built

UTIB is the bank part: the letters of Axis Bank. The fifth character is always the digit 0. 006045 is the part that names this branch.

The MICR code 700211218 is the number printed along the bottom of this branch's cheques. 700 is the city, 211 is the bank and 218 is the branch.
