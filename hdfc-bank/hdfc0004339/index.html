How the code HDFC0004339 is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. 004339 is the part that names this branch.

The MICR code 700240098 is the number printed along the bottom of this branch's cheques. 700 is the city (the same three digits that begin the PIN code 700005), 240 is the bank and 098 is the branch.
