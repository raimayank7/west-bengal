How the code BDBL0002153 is built

BDBL is the bank part: the letters of Bandhan Bank. The fifth character is always the digit 0. 002153 is the part that names this branch.

The MICR code 732750106 is the number printed along the bottom of this branch's cheques. 732 is the city (the same three digits that begin the PIN code 732122), 750 is the bank and 106 is the branch.
