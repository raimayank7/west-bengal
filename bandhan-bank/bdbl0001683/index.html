How the code BDBL0001683 is built

BDBL is the bank part: the letters of Bandhan Bank. The fifth character is always the digit 0. 001683 is the part that names this branch.

The MICR code 713750351 is the number printed along the bottom of this branch's cheques. 713 is the city (the same three digits that begin the PIN code 713146), 750 is the bank and 351 is the branch.
